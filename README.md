# Outlier OS — Beta
Plataforma educacional da **MAX OUTLIER**.

## Versão atual
Dashboard de progresso, Método Outlier em cinco níveis, Desafio Outlier 21 Dias, calculadora de reserva/margem, construtor de oferta, plano 30/90/365 e persistência local.

## Arquitetura atual
HTML/CSS/JavaScript estático publicado via GitHub Pages. Os dados ficam apenas no `localStorage` do navegador do usuário.

## Antes de comercializar
Esta beta **não possui autenticação real, banco de dados ou controle de acesso**. A próxima etapa comercial exige backend/auth e integração de checkout. Não coloque chaves privadas no código do GitHub Pages.

## Produto
**Método Outlier** é o produto. **Outlier OS** é a plataforma onde a experiência acontece.

> Material educacional; não constitui recomendação financeira ou de investimento nem promessa de resultados.
