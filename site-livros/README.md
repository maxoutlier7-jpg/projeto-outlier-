# Trilogia Modo Ação

Landing page em Next.js para venda da trilogia digital.

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Checkout

Defina:

```
NEXT_PUBLIC_STRIPE_CHECKOUT_URL=https://buy.stripe.com/...
```

O botão principal passa a direcionar para o Stripe Checkout.

## Deploy

Projeto preparado para Vercel. A raiz do projeto na Vercel deve ser `site-livros`.
